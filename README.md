# PruebaBackend-NetCore
Requisitos del equipo
- Tener Visual Studio 2018 o 2022 para mayor control
- Tener instalado EF Core Power Tools, la version mas reciente
- Trabaja bajo version .NET 8
  
NOTA: El archivo SLN se encuentra en el proyecto principal
en la carpeta PruebaBackendAPI

NOTA: Deben correr primero el docker-compose.yml del proyecto
PruebaBackend-NodeJS para tener la base de datos disponible para
usar los endpoints del proyecto

usuarios para utilizar en endpoint login: 
NombreUsuario: user1, Clave: clave1 o  user2 y clave2
